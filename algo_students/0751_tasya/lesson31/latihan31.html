Jarak Horizontal
A (3, 4) B (10, 4) d = ?
Titik A(3,4) dan B(10,4) memiliki nilai y yang sama, sehingga garis AB mendatar (horizontal). Berapa jarak AB?
Karena y sama, jarak hanya dihitung dari selisih nilai x: d = |10 − 3|
Jarak Vertikal
A (6, 2) B (6, 15) d = ?
Titik A(6,2) dan B(6,15) memiliki nilai x yang sama, sehingga garis AB tegak (vertikal). Berapa jarak AB?
Karena x sama, jarak hanya dihitung dari selisih nilai y: d = |15 − 2|
Jarak Diagonal
A (2, 3) B (6, 6) d = ?
Titik A(2,3) dan B(6,6). Garis AB miring, sehingga kita bentuk segitiga siku-siku bantu seperti gambar. Berapa jarak AB?
Δx = 6−2 = 4, Δy = 6−3 = 3. d² = Δx² + Δy² = 4² + 3² = 25
Jarak Diagonal
A (1, 2) B (9, 8) d = ?
Titik A(1,2) dan B(9,8). Berapa jarak AB?
Δx = 9−1 = 8, Δy = 8−2 = 6. d² = 8² + 6² = 64 + 36 = 100
Cari Koordinat
A (0, 0) B (x, 8) d = 17
Titik A(0,0) dan B(x, 8). Jika jarak AB = 17, berapa nilai x (x > 0)?
Δy = 8. Gunakan d² = Δx² + Δy² → 17² = Δx² + 8² → Δx² = 289 − 64 = 225
Konteks Nyata
🏞️ Pada peta sebuah taman, gerbang masuk berada di titik G(0,0) dan area bermain berada di titik B(5,12). Berapa jarak lurus dari gerbang ke area bermain?
G (0, 0) B (5, 12) jarak = ?
Δx = 5, Δy = 12. d² = 5² + 12² = 25 + 144 = 169
Konteks Nyata
🚁 Sebuah drone terbang dari titik awal D(3,2) menuju titik tujuan T(12,14) dalam lintasan garis lurus. Berapa jarak yang ditempuh drone tersebut?
D (3, 2) T (12, 14) jarak = ?
Δx = 12−3 = 9, Δy = 14−2 = 12. d² = 9² + 12² = 81 + 144 = 225
Triplet Pythagoras
Setiap pasangan (Δx, Δy) di bawah akan menghasilkan jarak d = √(Δx² + Δy²). Manakah pasangan yang menghasilkan d berupa bilangan bulat (tanpa bentuk akar)?
Hitung Δx² + Δy² untuk setiap pasangan, lalu cek apakah hasilnya bilangan kuadrat sempurna (seperti 25, 100, 169, ...).
Bentuk Akar
A (0, 0) B (3, 5) d = ?
Titik A(0,0) dan B(3,5). Berapa jarak AB? (Petunjuk: hasilnya tidak harus berupa bilangan bulat!)
Δx = 3, Δy = 5. d² = 3² + 5² = 9 + 25 = 34. Karena 34 bukan kuadrat sempurna, biarkan jawaban dalam bentuk akar.
